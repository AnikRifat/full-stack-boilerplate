# Tool guidance

Read the root and application `AGENTS.md` files. Backend Laravel Boost MCP configuration is project-local in `backend/.codex/config.toml`; start the Codex host from that application directory to load it. Configuration does not mean the tool is active in an already-running session. Boost generated package guidance and skills locally; refresh with `php artisan boost:update` and inspect managed changes.

Next.js ships version-matched documentation in `frontend/node_modules/next/dist/docs/`. Preserve its managed agent rules. Product documentation belongs in `docs/`.
